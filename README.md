# 📸 Visual Archive – Photography Portfolio Website

## 🌟 About the Project

**Visual Archive** is a modern and elegant photography portfolio website designed to showcase beautiful photographs and creative photography work.

The website provides a professional platform for photographers to display their work, introduce themselves, showcase photography services, explore packages, and receive booking inquiries from clients.

The main aim of this project is to create an attractive, user-friendly, and responsive website that presents photography in a creative way.

## ✨ Features

- **Home Page:** Attractive landing page with a professional design.
- **About Section:** Introduction to the photographer.
- **Photography Gallery:** Displays a collection of photographs.
- **Category Filters:** Filter images based on different categories.
- **Image Preview:** Click on images to view them in a larger lightbox.
- **Services Section:** Displays available photography services.
- **Packages Section:** Provides different photography packages.
- **Booking Section:** Allows visitors to submit their booking inquiries.
- **Responsive Design:** Designed to work across desktop and mobile screen sizes.
- **Interactive Navigation:** Easy navigation between website sections.

## 🛠️ Technologies Used

- HTML5 – For creating the website structure.
- CSS3 – For styling and designing the website.
- JavaScript – For interactive features and functionality.
- Tailwind CSS – For responsive layouts and styling.
- Google Fonts – For beautiful typography.
- Font Awesome – For icons.
